# Formulario de inscripción: cuatro variantes

Un mismo formulario de inscripción, validado con JavaScript puro (sin librerías), resuelto en
cuatro estilos visuales distintos. Sirve para ver cómo cambia la presentación sin tocar la lógica.

**[Ver la versión base en vivo](https://antonioyurquina.github.io/VariantesDeFormulario/)**

## Qué valida

- **Nombre y apellido:** obligatorio, solo letras y espacios, mínimo 3 caracteres.
- **DNI:** obligatorio, exactamente 8 dígitos.
- **Fecha de nacimiento:** obligatoria, edad mínima de 18 años calculada de forma exacta.
- Los mensajes de error aparecen debajo de cada campo y el campo cambia de estado (error / válido).
- Un botón adicional hace tres preguntas progresivas y muestra las respuestas en la página.

## Stack

`HTML` `CSS` `JavaScript` — sin dependencias ni paso de build. Para verlo en local alcanza con
abrir `index.html` en el navegador.
